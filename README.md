# 海岛奇兵小队长模拟

一个纯前端的小队长抽卡概率模拟器，用来估算「抽到想要的队长 / 命座」需要多少抽、成功率多少。

## 在线使用

部署后访问：`https://zyj52742-cloud.github.io/boom-beach-squad-sim/`

也可以直接下载 `index.html`，双击用浏览器打开，全程本地运行。

## 功能

- **35 个队长图鉴**：精英中尉、中尉、中士、赛博中士，标注国服「已出 / 即将上线」和卡池起止时间
- **抽卡模拟**：勾选目标队长、填目标命数（0~5 命），用蒙特卡洛模拟算出达成概率
- **资源规划**：当前钥匙 + 海岛宝藏 + 队长部署活动 + 声纳站 + 每日免费一抽，按目标日期累计
- **日期选择**：年月日下拉，带春节 / 中秋 / 国庆快捷跳转
- **提前出概率表**：单池抽当期队长的累计概率；全部目标的总消耗概率
- **命数对照**：金医档位 × 等待天数，看「再升一命」的代价

## 机制说明

- 精英池：首金 50% 出当期主打，未中则次金 100%，单池期望 **90 抽**、最坏 **160 抽**
- 命数换算：**1 本体 = 0 命**，6 本体 = 满命，N 命需要 N+1 个本体
- 常驻池：中尉平均 60 / 保底 80；中士平均 30 / 保底 40，池内等概率随机

## 数据来源与时效

数据截至 **2026-10-23**，卡池时间取自官方活动日历（BWIKI 转载）与实机视频。官方更新后数据可能过期，以游戏内为准。
